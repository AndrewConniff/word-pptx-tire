Copilot Follow-Along Demo (Word + PowerPoint)

Single-page runbook | Uses in-file editing + Chat alternatives + PPT template flow

Use this page as your only instruction sheet during delivery.

Includes chart creation from the shared Excel file, Word in-file edits, Chat-grounded alternatives, and PowerPoint creation both from Chat and inside the branded template.

Files

Run order

1. Build a chart visual from the shared Excel file.
2. Edit source docs directly in Word.
3. Run doc-grounded alternatives in Copilot Chat.
4. Create a PPT outline from Chat.
5. Open the branded PPTX template and build/refine slides in-file.

Section A - Analyst chart from Excel

A1 - Build chart
WHERE THIS PROMPT HAPPENS: Excel, open "Canada-Wide-Winter-Tire-Sales-Weather-2023-2026.xlsx".
Create a chart comparing weekly Winter Tire Sales (CAD) and Snowfall (cm) by region.
Use a layout that is easy to explain in 60 seconds.
A2 - Capture insights
WHERE THIS PROMPT HAPPENS: Excel, same workbook as A1.
Summarize 3 insights from this chart that matter for store and auto service readiness.

Section B - Word in-file edits

W1 - Rewrite procedure opening
WHERE THIS PROMPT HAPPENS: Word, open "Winter-Season-Readiness-Procedure.docx".
Rewrite the opening section in plain, friendly language for store associates.
Keep all actions and dates intact.
W2 - Convert visit follow-ups to table
WHERE THIS PROMPT HAPPENS: Word, open "Store-Auto-Service-Visit-Notes.docx".
Convert key follow-ups into a table with:
Store | Issue | Owner role | Due date | Escalation needed.

Section C - Chat alternatives using the same docs

C1 - Bulletin from docs
WHERE THIS PROMPT HAPPENS: Copilot Chat with both docs attached (Procedure + Visit Notes).
Using Winter-Season-Readiness-Procedure.docx and Store-Auto-Service-Visit-Notes.docx,
draft a one-page weekly operations bulletin for stores and service teams.
Include 5 priority actions and 3 risks.
C2 - Leadership rewrite
WHERE THIS PROMPT HAPPENS: Copilot Chat, same conversation context as C1.
Rewrite this bulletin for regional leadership in 6 concise bullets with owner/date actions.

Section D - Create PowerPoint from Chat

D1 - Slide outline from Chat
WHERE THIS PROMPT HAPPENS: Copilot Chat with "Winter-Season-Plan-Leadership.docx" and chart insights from A2.
Create a 7-slide leadership deck outline with:
Context, trend insight, readiness actions, risks, asks, and next-week timeline.
Use executive tone and concise slide headlines.

Section E - Build inside branded PPTX template

P1 - Build slides in template
WHERE THIS PROMPT HAPPENS: PowerPoint, open "MapleWheel-Branded-PowerPoint-Template.pptx".
Using this outline, create slides in this deck using the current template style.
Keep each slide to one headline and 3-4 bullets.
P2 - Add slides and reorder
WHERE THIS PROMPT HAPPENS: PowerPoint, same template deck as P1.
Add one slide titled "Risks and asks" and one slide titled "Decisions needed this week".
Then reorder slides for this flow:
Context -> Trends -> Actions -> Risks -> Decisions -> Timeline.
P3 - Speaker notes
WHERE THIS PROMPT HAPPENS: PowerPoint, same template deck as P1/P2.
Draft speaker notes for the "Trends" slide and "Risks and asks" slide (60-90 seconds each).

Preparation checklist

  1. Upload all sample files to one OneDrive/SharePoint folder.
  2. Open Excel, Word, PowerPoint, and Copilot Chat in the same tenant/account.
  3. Open the shared Excel workbook first and dry-run A1/A2.
  4. Dry-run W1/W2 in-file and C1/C2 in Chat.
  5. Open the branded PPT template and dry-run P1/P2/P3.
  6. Keep this page open during delivery so no separate doc is needed.
